Configurações da loja Nome, WhatsApp e aparência. Lembre de Publicar depois de alterar.

O número do WhatsApp deve ter só dígitos: 55 (Brasil) + DDD + número. Ex.: 5511987654321.

Produtos Adicione, edite ou remova. As alterações só vão para a loja após Publicar.

Publicar alterações Baixe os arquivos atualizados e substitua-os no site para publicar.

Ao clicar em Publicar, dois arquivos serão baixados: products.js e config.js. Substitua-os na pasta js/ do seu site (commit/push no GitHub) para atualizar o catálogo. Veja o passo a passo no README.

Publicar direto no GitHub (opcional) Envie as alterações direto para o repositório, sem baixar arquivos.

⚠️ O token dá acesso de escrita ao repositório. Ele fica salvo só neste navegador — nunca é enviado para o site nem gravado no catálogo. Use um token fine-grained limitado a este repositório. Passo a passo de como criar no GUIA.
